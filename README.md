# WebStudio — переосмислення навчального проєкту

Адаптивний HTML/CSS/JavaScript без збірки та залежностей. Оригінальний навчальний сайт Олексія Сандульського, оновлений у 2026 році за допомогою ШІ.

## Як відкрити у VS Code
Відкрийте папку `dist`. Запустіть `index.html` через Live Server або просто відкрийте файл у браузері.

- `dist/index.html` — структура й тексти.
- `dist/style.css` — оформлення, адаптивні правила, reduced-motion.
- `dist/app.js` — кейси, фільтри, меню, діалогові вікна, завантаження брифу.
- `dist/images` — зображення з оригінального навчального проєкту.
- `dist/pages/portfolio.html` — окрема сторінка портфоліо з фільтрами.

Форма перевіряє поля та завантажує текстовий бриф локально. Вона НЕ відправляє заявки та НЕ зберігає дані на сервері. Для приймання реальних заявок потрібно підключити погоджений backend або сервіс форм та вказати справжні контакти.
